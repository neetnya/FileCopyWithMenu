# FileCopyWithMenu · 目录树复制工具

一个 Windows 桌面小工具：左右两栏目录树，左侧多选文件/文件夹（选中文件夹会递归包含其下所有内容），
点中间的 **【→】** 就把目录结构和文件一起复制到右侧目录。

典型的适用场景：把散落在多个目录里的东西按原有层次整理到一个目标位置——比如把若干工程目录里的
素材、素材的子目录结构，一次性"搬"进归档盘，而不用在资源管理器里一层层展开复制。

---

## 1. 特性一览

- **左右两栏目录树**，中间圆形 **→** 复制按钮与 **⇄ 交换** 目录按钮，支持从资源管理器直接拖入文件夹
- **多选**：Ctrl 点选切换、Shift 点选范围、Ctrl+Shift 范围加选、Shift+↑/↓ 扩展选区、Ctrl+A 全选可见项、Space 切换、Esc 清空
- **选中文件夹 = 递归**：整个子树的目录结构和文件都会被复制，且自动去重（同时选中父子目录不会重复复制或重复统计）
- **保留相对路径**：每个选中项按"相对左侧根目录的路径"落到右侧，不改变层级关系
- **异步懒加载与全展开**：目录枚举在后台线程执行，大目录树与子树均分块异步展开，界面不卡死
- **四种冲突策略**：覆盖 / 跳过 / 自动重命名（`名称 (1).ext`）/ 仅覆盖较新或不同大小（增量同步）
- **流式复制与原子落盘**：按总字节数实时显示进度与速率（MB/s），复制大文件时可秒级取消，先写临时文件再原子替换避免残留损坏文件
- **可选保留时间戳**：文件沿用源文件的修改时间与创建时间，文件夹沿用源文件夹的修改时间
- **长路径支持**：路径超过 260 字符也能复制（`\\?\` 前缀 + 清单 `longPathAware`）
- **安全扫描与空间预检**：目录联接点 / 符号链接目录不递归（避免成环）；复制前预检目标磁盘剩余空间
- **日志筛选与失败重试**：支持“仅看错误”筛选以及“重试失败项”一键补传

## 2. 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / Windows 11（64 位） |
| 运行 | **.NET 8 Desktop Runtime**（8.0.x，x64） |
| 构建（可选） | .NET SDK 8.0 或更高 |
| 权限 | 普通用户即可；访问受保护目录时按系统规则可能失败，会在日志里记录 |
| 依赖 | 无。不需要 Python、不需要任何第三方 NuGet 包 |

程序是**框架依赖发布**（非自包含），所以目标机器必须有 .NET 8 Desktop Runtime。
可以用 `dotnet --list-runtimes` 检查是否已安装 `Microsoft.WindowsDesktop.App 8.x`。

## 3. 手动构建

```bat
dotnet build FileCopyWithMenu.csproj -c Release -o dist
```

或直接运行 `build.bat` / `launch.bat`。

## 4. 操作与快捷键

### 全局

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + →` | 把左侧选中项复制到右侧（等同点中间按钮） |
| `F5` | 刷新左右两侧目录树 |

### 树里（鼠标 / 键盘）

| 操作 | 作用 |
| --- | --- |
| 单击节点 | 单选该节点（清掉之前的选择） |
| `Ctrl` + 单击 | 切换该节点的选中状态 |
| `Shift` + 单击 | 从锚点到该节点做范围选择 |
| `Ctrl + Shift` + 单击 | 保留已有选区并追加范围选择 |
| 双击文件夹 | 展开 / 折叠该文件夹 |
| 拖入文件夹 | 将拖入的文件夹设为当前面板的根目录 |
| `↑` / `↓` | 移动当前项（自动滚动到可见区域） |
| `Shift + ↑` / `Shift + ↓` | 保持已有选择，扩展选区到相邻节点 |
| `→` | 展开当前文件夹；已展开则移到第一个子项 |
| `←` | 折叠当前文件夹；已折叠或为文件时跳回父目录 |
| `Space` | 切换当前项的选中状态 |
| `Ctrl + A` | 全选当前**可见**节点 |
| `Esc` | 清空选择 |

### 上下文菜单

- **复制到右侧** `Ctrl+→`（仅左侧面板显示）
- **展开 / 折叠**、**展开整个子树**（异步分块，含上限保护）
- **新建文件夹…**
- **用资源管理器打开**、**复制完整路径**
- **全展开** / **全折叠**

## 5. 复制规则与选项

设左侧根目录为 `D:\A`、右侧根目录为 `E:\B`：

| 左侧选中的东西 | 结果 |
| --- | --- |
| 文件 `D:\A\docs\a.txt` | `E:\B\docs\a.txt` |
| 文件夹 `D:\A\docs` | `E:\B\docs\...` 整个子树一起过去 |
| 左侧**根目录本身** `D:\A` | `E:\B\A\...` |
| 同时选中父目录与子目录 | 自动去重，仅按父目录复制一次 |

冲突策略：
- **覆盖**：替换目标同名文件（自动清除只读属性；若目标为同名文件夹则报错跳过而不删除整个文件夹）
- **跳过**：保留目标已有项；若目录名被同名文件占用则跳过整棵子树
- **自动重命名**：新文件/目录命名为 `名称 (1).ext`
- **仅覆盖较新/不同大小**：若目标文件大小一致且修改时间不旧于源文件（2 秒容差），则跳过
